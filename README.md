# 🚲 Pedal Fácil

Aplicação web simples para um site de locação de bicicletas, desenvolvida durante as aulas do curso Técnico em Desenvolvimento de Sistemas com o objetivo de fixar os fundamentos do desenvolvimento web front-end e a escrita de código simples e limpo.

## 🖼️ Demonstração

- Caso tenha se interessado, confira o projeto através do link: [Pedal Fácil](https://seu-link-aqui.vercel.app)

## ✨ Funcionalidades

- Uma tela principal com informações de funcionalidade
- Apresentação dos modelos de bicicletas disponíveis para locação;
- Formulário simples de reserva da bicicleta selecionada;
- Layout responsivo e amigável para navegação em dispositivos móveis;

## 💻 Tecnologias Utilizadas

- **HTML5** — estrutura e semântica das páginas
- **CSS3** — estilização, cores e responsividade do layout
- **JavaScript (Vanilla)** — lógica básica de interatividade e manipulação do DOM

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido como atividade prática durante o curso **Técnico em Desenvolvimento de Sistemas**. O foco principal da aplicação foi exercitar os primeiros passos no desenvolvimento front-end, aplicando conceitos fundamentais de forma clara e simples.
